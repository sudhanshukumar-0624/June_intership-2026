# 🎮 Project 02 — Gaming Hub Website

A visually immersive gaming-themed website that showcases popular video games with a hero section, featured game cards, and a reviews section. Built with HTML and CSS during a web development internship at UNLOX.

---

## 🖥️ Live Preview

🔗 **Deployed URL:** [https://gaminghub-landingpage.netlify.app](https://gaminghub-landingpage.netlify.app)

Or open `index.html` directly in any modern browser — no server required.

## ✨ Features

- **Hero Section** — Full-screen cinematic banner with welcome text and CTA button
- **Featured Games Grid** — Cards showcasing top gaming titles with cover art
- **Game Posters** — GTA V, God of War, Need For Speed, Prince of Persia, The Last of Us, Witcher 3, Call of Duty, Spider-Man, Uncharted
- **Reviews Section** — Community/critic review area
- **Contact Section** — Get in touch form
- **Responsive Navigation** — Home, Games, Reviews, Contact links

## 🎨 Design Highlights

- Dark gaming aesthetic with bold typography
- Full-screen hero overlay with gradient effect
- Game card grid with hover interactions
- Immersive cinematic feel throughout

## 🚀 How to Run
